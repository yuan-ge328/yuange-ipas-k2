源格 YuanGe｜iPAS 中級科目二衝刺教室 V1.1
官方50題費曼解析＋39–50題逐行／情境判讀｜更新指南

【從 V1.0 升級：請用「更新包 ZIP」】
1. 先從 V1.0 網站「設定」匯出學習紀錄 JSON，另存備份。
2. 在電腦解壓縮「V1.1_GitHub更新包.zip」。
3. 進入 GitHub：https://github.com/yuan-ge328/yuange-ipas-k2
4. Code → Add file → Upload files，把更新包內的 6 個網站檔案拖入儲存庫根目錄。
5. GitHub 會覆蓋同名檔案並新增 explanations.js；確認後 Commit changes。
6. 等 GitHub Pages 部署完成，開啟：https://yuan-ge328.github.io/yuange-ipas-k2/
7. 首頁應顯示 V1.1，點「費曼解析教室」查看題目，再試做 10 題交卷確認解析。

【V1.1 六個需上傳的檔案】
index.html　網站版本及載入新的解析資料
app.js　　　費曼學習介面、考後四選項解說；沿用 V1.0 學習資料鍵
style.css　　費曼解析手機版排版
explanations.js　50 題費曼解析與 12 題逐步判讀
sw.js　　　新版離線快取清單／快取識別
manifest.webmanifest　網站安裝識別版本

【本版保留】
原始官方 questions.js、全部圖表、原卷 PDF、Icon；50 題／90 分鐘模擬考、10 題快刷、錯題本、JSON 備份還原；原學習紀錄鍵 yuange_ipas_k2_v1_state 不變。

【教材依據與限制】
原題和答案：115 年第一次中級科目二官方公告試題（115/05/23）。
新增 50 題「費曼解析」為 AI 編寫的學習輔助，非 iPAS 官方解析。
第 39–50 題共 12 題列於官方「程式題」，但部分題目是模型／門檻情境判讀，沒有 Python 程式碼，故使用判讀步驟而不是偽造逐行程式。
第 1、18、24、30、38、49 題另附技術／題意限制提醒，尤其第49題官方答案B，但選項A在二元分類條件下可能同樣可運行。
離線更新須在連線時載入完整新版一次；iPhone 尚待個人實機驗收。

【驗收檢查】
□ 首頁 V1.1；費曼解析教室可進入
□ 50 題都有 A–D 四選項理由
□ 39–50 題有程式逐行／情境判讀步驟
□ 50 題全真模考仍可開始、倒數90分鐘
□ 交卷後才揭曉正解；錯題仍可回補
□ 關閉再重開，舊有進度未遺失
□ iPhone 連線更新後，飛航模式下可讀已快取解析

【復原】
若網站版本出現異常，可從 GitHub Commit history 還原 V1.0 版本。避免直接清除瀏覽器或刪除 iPhone 主畫面 App，因本機學習進度可能遺失。
