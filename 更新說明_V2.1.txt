如何上傳到 GitHub Pages：
A. 先至「我的」→「匯出進度 JSON」，備份學習紀錄。
B. 解壓縮這份 ZIP。
C. 前往 https://github.com/yuan-ge328/yuange-ipas-k2 ，選 Code → Add file → Upload files。
D. 將 index.html、app.js、style.css、sw.js、manifest.webmanifest 共 5 個檔案放在儲存庫根目錄（覆蓋原有同名檔）。
E. 按 Commit changes。無需重新設 Pages，也無需重傳 assets/、題庫或 PDF。
F. 網站上線後確認 V2.1，按「開始今日任務」測試；如仍顯示舊首頁，請關閉頁面並重新開啟、重新載入後驗證。
